## Overview

**Suno** is the official music bot by the [Kavach Team](https://suno.kavachbot.com), crafted to deliver the perfect soundtrack for every mood and moment. Turn your Discord server into a high-quality music space — built for servers that want stable playback, multiple music sources, intelligent autoplay, and full DJ-level control without compromise.

## Commands

**Music — 20 Commands**

| Command | Description |
|---|---|
| `/play` | Play from search or direct link |
| `/search` | Interactive search results |
| `/join` | Join voice channel |
| `/leave` | Leave voice channel |
| `/pause` / `/resume` | Control playback |
| `/skip` | Skip current track |
| `/previous` | Play the previous track |
| `/stop` | Stop music and clear queue |
| `/nowplaying` | Live track display with progress |
| `/queue` | Detailed queue viewer |
| `/loop` | Loop track or entire queue |
| `/shuffle` | Randomize the queue |
| `/autoplay` | Toggle smart recommendations |
| `/clearqueue` | Clear entire queue |
| `/remove` | Remove selected tracks |
| `/seek` | Jump to any timestamp |
| `/volume` | Set volume (0 – 200%) |
| `/grab` | Save current track to DM |
| `/lyrics` | Fetch synced lyrics |

**Server Configuration — 7 Commands**

| Command | Description |
|---|---|
| `/247` | Stay in voice channel permanently |
| `/prefix` | Set custom server prefix |
| `/dj` | Configure DJ role system |
| `/vcstatus` | Set custom voice channel status |
| `/ignoreChannelAdd` | Ignore specific text channels |
| `/ignoreChannelList` | View all ignored channels |
| `/ignoreChannelRemove` | Remove a channel from ignore list |

## Getting Started

**1.** Invite Suno using the link above.

**2.** Join a voice channel in your server.

**3.** Use `/play <song name or link>` to start listening.

**4.** Use `/search` for interactive results, or `/filter` to customize your audio.

> Need help? Use `/support` inside Discord or join our [Support Server](https://discord.gg/kavach).
